# Unreal_Assignment

For this assignment I was tasked with creating an Unreal engine game / tech-demo utilizing Blueprint scripting techniques.
It was a group assignment with teams of 3 and the game / tech-demo we created had to have 6-8 mins of original gameplay at least. Other than that there were no other constraints.
The workload was split 3 ways inside our team and I was tasked with gameplay mechanics in general. I chose to test my knowledge and implemented a procedurally generated dungeon crawler system for our main gameplay loop. 

Developed with Unreal Engine 5
